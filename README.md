# Flutter Product Catalog

A Flutter application that displays a list of products in card layouts and provides a dedicated detail page for each product.

## Features

- Display a list of products.
- Show product information in card layouts.
- Navigate to the product detail page.
- Display detailed information about the selected product.

## Tech Stack

- **Flutter** — Cross-platform application framework.
- **Dart** — Programming language.

## Getting Started

### Prerequisites

Make sure you have installed:
- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/USERNAME/flutter-product-catalog.git
   ```

2. Navigate to the project directory:

   ```bash
   cd flutter-product-catalog
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
